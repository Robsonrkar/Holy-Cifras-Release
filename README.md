# Holy Cifras — versões para atualização

Este repositório é **público** e guarda apenas as **versões do programa Holy Cifras** (aba *Releases*).
O Holy Cifras consulta a última release para avisar de atualização e baixar o `HolyCifras.exe` (conferido por SHA-256).

O código-fonte fica em um repositório privado. Não é preciso baixar nada daqui à mão: use **Ajuda → Verificar atualização** dentro do programa.
